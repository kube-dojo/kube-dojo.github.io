# PR comments

- Post only within the task's authorization and scope. Attribute the actual writing agent using verified model and harness information; if unavailable, say what is known without guessing. Preserve relevant run, head and source attribution.
- Distinguish quoted reviewer findings from the lead's own judgment; never impersonate the original author or a human reviewer, invent identities or evidence, or present an agent review as human review.
- State the conclusion and supporting evidence concisely, separate observation from judgment, and avoid exposing private information. Use a PR comment rather than GitHub approval when author and reviewer share an identity.
- Verify the comment or reply was posted to the intended target. Record failures and leave any unposted finding unresolved; do not claim publication from a prepared draft.
