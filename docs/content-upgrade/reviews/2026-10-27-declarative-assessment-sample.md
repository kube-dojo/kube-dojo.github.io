**Design.** If five replicas is the intended durable capacity, edit the manifest to five, review and commit that intent in the chosen repository workflow, apply through the designated owner, then inspect rollout, readiness and service behavior. A successful apply alone does not establish application recovery. If Git still declares three, the next application of that declaration can restore three; the scale command is not the durable record. Separate infrastructure ownership from workload ownership and avoid multiple controllers writing the same fields without an explicit policy.

Deleting a Pod cannot fix an incorrect environment setting retained in its template. For ConfigMaps and Secrets, identify whether the application consumes environment variables, a regular mounted volume or a `subPath` mount, and whether it actually reloads updated files; a changed API object does not itself establish that the process uses the new value.
