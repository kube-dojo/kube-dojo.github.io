# Full send

- The accountable lead owns one change through implementation, verification, review, PR, merge and closeout, including publication when applicable. Explicit full-send authorizes routine task-owned delivery actions; proceed without repeated human confirmation.
- Follow AGENTS.md and, for epic work, [drive-epic](../drive-epic/SKILL.md). Respect higher-priority restrictions, spending and scope limits; resolve routine in-scope choices and fix failures autonomously. Delivering a PR, including bridge delivery, does not itself authorize merge or publication.
- Run [review-loop](../review-loop/SKILL.md); resolve material findings. Merge only when a valid independent cross-family approval and passing applicable checks name the same unchanged pushed head being merged. A green build or PR alone is not acceptance.
- Confirm the actual merge and, when publication is in scope, the completed deployment and relevant public behavior. Preserve evidence and safely handle only authorized cleanup; never force away active, dirty or unpushed work.
- Report the actual disposition, exact revision, verification and limits, unresolved risks, ownership and next action. Stop at an unresolved material blocker or a higher-priority restriction and report it.
