# KubeDojo delivery and review

Use the installed full-send, full-stop, modernize, takeover, review-loop and
pr-comments skills with `AGENTS.md` and `docs/ops/workspace-hygiene.md`.
The assigned brief sets the delivery and publication scope. A bridge PR
handoff leaves merge with the organizer. When publication is in scope,
verify the deployed behavior before closeout.

- For a full-stop handoff, verify the PR is open, auto-merge is disabled and
  the PR is out of the queue. Recheck before pushes and at handoff. Give the
  receiving owner the exact revision, check results, findings and residuals.
- When taking over or modernizing work, reconcile the current base, owner,
  exact revision, live leases and unpushed changes. Preserve the original
  goal, authorship, evidence and review counter. If the work is already
  satisfied, report the evidence and resolve its disposition without a rebase.
- For code, count independent review invocations per PR, including changed
  heads. For whole-page curriculum, count them per audit across seeds and
  packets. Preparation without invocation consumes no round. Failed,
  incomplete and inconclusive invocations consume a round. Use the installed
  policy for PRs. A whole-page audit allows five invocations unless the
  brief sets a smaller cap or the user explicitly grants additional rounds.
  Renaming the audit or changing reviewers leaves the counter in place.
  The source, rubric and practice evidence for a complete page still applies.
- Keep stable finding IDs with evidence and dispositions. Escalate a
  supported disagreement under the epic workflow. Preserve the required
  source receipt and its seed or revision binding.
- Attribute public comments to the agent that wrote them. Use a comment if
  the author and reviewer share a GitHub identity. Verify where the comment
  landed and report any publication failure with its remaining finding.
- Register and audit task workspaces before cleanup. A larger issue that
  remains open does not retain a workspace whose packet has completed.
